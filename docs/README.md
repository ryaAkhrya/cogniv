# Cogniv - AI Cybersecurity Landing Page

Welcome to **Cogniv**, a sleek & futuristic B2B SaaS landing page designed for an AI-driven cybersecurity startup.

## 🚀 Tech Stack
- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS (Dark Mode, Glassmorphism, Neon Glow)
- **Database/BaaS**: Supabase (Contact Form & Lead Capture)

## 🎨 Brand & Logo Concept
- **Logo Idea**: Abstract letter "C" forming a minimalist shield, intersected by a glowing neural network node.
- **Colors**: Deep Dark Black (`#09090b`), Neon Purple (`#8b5cf6`), Electric Blue (`#3b82f6`).
- **Typography**: Space Grotesk (Headings), Inter (Body).

## 🛠️ How to Run
1. `npm install`
2. Set up `.env.local` with Supabase keys.
3. `npm run dev`
